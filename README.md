# Ashutosh Singh — Personal Portfolio Website

A responsive personal portfolio built with HTML5, CSS3, and vanilla JavaScript.

## Included Files
- `index.html` — Semantic page structure (About Me, Education, Skills, Projects, Contact)
- `style.css` — Responsive layout, CSS custom properties, and dark/light theme styling
- `script.js` — Theme toggle, mobile menu, typing effect, skill/project filters, modal preview, and form validation

## Before Deploying
1. Update the Class X and Class XII school details in `index.html`.
2. Replace `github.com/[your-username]` and add your real project repository links in `script.js`.

## Deploy to GitHub Pages
1. Create a new public repository on GitHub (e.g. `portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of the repository.
3. Open **Settings → Pages** in your GitHub repository.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
5. Wait 1–2 minutes for GitHub Pages to publish your live URL (`https://<your-username>.github.io/portfolio/`), then test it on desktop and mobile before submitting.
